# LoginApp3 - Android Login App with Dashboard

This Android app demonstrates a complete **login system** and a **dashboard screen** with navigation cards.

---

## ✨ Features

- **Login Screen** – Simple email and password form.
- **Landing Dashboard** – Displays four cards:
  - 🧍‍♂️ Profile  
  - ⚙️ Settings  
  - 💬 Messages  
  - 🚪 Logout
- **Navigation Flow** – Moves between screens using `Intent`.
- **UI Enhancements** – Gradient background, modern CardView layout, and toast interactions.

---

## 🧭 Navigation Flow

1. **LoginActivity** → User enters email and password  
2. On successful login → navigates to **LandingActivity**  
3. Dashboard cards perform different actions (toast or navigation)
4. Logout returns to login screen
